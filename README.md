## Python fundamentals
### Project: fantasy adventure game
#### 1. What is it? What does it do?
This project is called "Green Dragon Quest: A dungeon crawler adventure". It is a text-based fantasy adventure game inspired by Dungeons & Dragons.
The a player fights their way through a dungeon whose rooms are filled with dangerous creatures, powerful equipment and rewards both valuable and peculiar.

#### 2. Main features
* Go on an adventure by fighting your way through 7 dungeon rooms, encountering various enemies and even dragons!
* Interactive mode: use your keyboard to make player choices. This is the usual game mode.
* Automatic mode: the player's choices are automated by the game. Attack choices are randomised. This mode is mainly useful for testing.
* Combat: fight against creatures in each room in the dungeon.
* Roll a dice to hit: attacks can hit or miss depending on the result of a dice roll and the stats of the characters involved.
* Attack damage varies: the damage of each attack uses a dice roll, so its damage varies for each use.  
* Attack types: choose from different attack types, some which are limited in their number of uses.
* Use items: use items like health potions to regain health.
* Equipment: change the player's weapon and armour to become more powerful.
* Player progression: level up by defeating enemies and gaining experience points.
* Explore the room after its enemies have been defeated. You can loot, view status information, show your inventory, use items or change equipment. You can also rest to regain your health points and abilities.
* Customise your adventure by editing your player in `player_data.py`, or the dungeon in `dungeon_data.py`.

#### 3. How to run it
1. Clone this repo.
2. Navigate to `python_fundamentals/project` using your terminal.
3. Run `python start.py` to start the game.
4. Follow the instructions on the screen to run the game. Choose from starting a new game (interactive mode), or running the game in automatic mode. Make your choice using keyboard input.
